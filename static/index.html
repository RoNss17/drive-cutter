Drive Cutter

Cut segments from Google Drive and WeTransfer videos without downloading the full file.

How it works

01
Range requests
FFmpeg asks the server for specific byte ranges instead of the entire file, using HTTP 206 Partial Content.
02
Input seeking
Placing the seek flag before the input tells FFmpeg to jump directly to your timestamp before downloading.
03
Stream copy
The segment is copied without re-encoding, so the output is fast and lossless. Only keyframe-aligned cuts.
